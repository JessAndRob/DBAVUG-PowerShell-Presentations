# Introduction to PowerShell via dbatools

Ready to dive into PowerShell but not sure where to start? Join us for an accessible introduction to PowerShell by completing database administration tasks. This session is designed for DBAs and data professionals who want to harness the power of automation but may feel intimidated by scripting.

In the first half of this session, we'll cover PowerShell fundamentals that every DBA should know. You'll learn about cmdlets, the pipeline, objects, and basic syntax through practical examples that relate directly to your daily work.

The second half focuses on dbatools - often called "the gateway drug to PowerShell" - a free, open-source PowerShell module containing almost 700 commands designed specifically for SQL Server management. We'll demonstrate how dbatools can simplify common DBA tasks such as:

- Backups and restores
- Configuration management
- Database migrations
- And more…

By the end of this session, you'll have a foundation in PowerShell basics and practical experience with dbatools commands that you can immediately apply to your environment. Whether you're managing one server or hundreds, you'll discover how PowerShell and dbatools can save you time, reduce errors, and make your life significantly easier.

No prior PowerShell experience required - just bring your curiosity and willingness to learn!
